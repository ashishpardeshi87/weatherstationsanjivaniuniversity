Cinematic per-condition loop videos go here. The scene auto-detects them.

Drop MP4 files named exactly by condition key (H.264, seamless loop, ~1080p):

  sunny.mp4          - frog character relaxing in a chair on a sunny beach
  partly.mp4         - frog lounging under drifting clouds
  cloudy.mp4         - frog chilling in cool grey daylight
  rain.mp4           - frog under an umbrella in the rain
  storm.mp4          - frog huddled under umbrella, lightning
  clear-night.mp4    - frog stargazing in a chair at night
  cloudy-night.mp4   - frog cozy under moody night clouds

When a matching file exists it crossfades in over the illustrated scene
automatically. Missing files simply fall back to the SVG scene.
